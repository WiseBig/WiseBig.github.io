MYGAME 포트폴리오 — 다크 게임 라이브러리 스타일

구성
- index.html: 홈페이지 내용 및 게임/QA 도구 카드
- style.css: 네이비 배경 + 블루 포인트, 반응형 카드 레이아웃
- script.js: 연도 표시, YouTube 썸네일 재생, 로컬 영상 재생
- images/: 기존 프로젝트 이미지 폴더를 여기에 넣으세요.
- videos/: 기존 로컬 영상 파일을 여기에 넣으세요.

참고
- 게임 다운로드 링크와 YouTube 영상 ID는 기존 홈페이지의 값을 유지했습니다.
- QA 도구 다운로드 링크는 제공된 실제 주소가 없어서 이메일 문의 링크를 유지했습니다.
- 실제 구현 기능과 일치하는지 게임 설명을 게시 전에 확인하세요.
- VS Code에서 index.html을 Live Server로 실행하면 확인할 수 있습니다.
